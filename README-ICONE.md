# Meu Bullet Journal — versão com ícone para iPhone

Envie para a **raiz** do repositório GitHub Pages estes seis arquivos:

- `index.html`
- `icon-180.png` (ícone usado pelo iPhone)
- `icon-192.png`
- `icon-512.png`
- `favicon.png`
- `manifest.webmanifest`

No GitHub use **Add file → Upload files**, selecione os seis arquivos e confirme **Commit changes**. Aguarde a publicação em **Actions**.

No iPhone, remova o atalho antigo da tela inicial (isso não exclui os dados do banco), abra o site **no Safari**, toque **Compartilhar → Adicionar à Tela de Início**. Se a imagem antiga persistir, atualize a página no Safari e crie o atalho novamente.

A configuração de login e banco Supabase do HTML foi mantida. Faça backup de seus registros antes de substituir versões, por precaução. A instalação na tela inicial não significa que o site funcione offline: a sincronização e o login ainda exigem internet.
